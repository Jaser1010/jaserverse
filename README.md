# Jaserverse — Personal Portfolio Website

https://jaser1010.github.io/jaserverse/

## About the Project

**Jaserverse** is a clean and professional portfolio designed to showcase my backend-focused projects, skills, and experience.  
The site is intentionally minimal and technical, targeting recruiters and engineers looking for backend development expertise.

It is structured to be easily expandable as I add more projects and experience over time.

## Local Development

```bash
git clone https://github.com/Jaser1010/jaserverse.git
cd jaserverse
```

Run locally:
```bash
python -m http.server 5500
```

Open:
```
http://localhost:5500
```

---

## Deployment

Configured with **GitHub Pages**  
Repository → Settings → Pages → Branch: `master` → `/ (root)`
